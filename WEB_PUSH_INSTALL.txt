ShumDev — Web Push для новых заявок

Архив содержит только новые/изменённые файлы. Распаковать поверх текущей папки проекта ShumDev на компьютере отца.

1. Установить зависимости:
   npm ci

2. Сгенерировать VAPID-ключи ОДИН РАЗ:
   npx web-push generate-vapid-keys

3. Не перезаписывать существующий .env. Добавить в него:
   VAPID_PUBLIC_KEY=...
   VAPID_PRIVATE_KEY=...
   VAPID_SUBJECT=mailto:ваш-email

   Ту же пару PUBLIC/PRIVATE перенести в .env на production-сервере.
   Ключи не коммитить в Git.

4. Применить БД:
   npx prisma generate
   npx prisma migrate deploy

5. После деплоя:
   pm2 restart shumdev --update-env
   nginx -t
   systemctl reload nginx

6. В ShumDev Control:
   Настройки -> Web Push -> Включить уведомления -> Тестовое уведомление.

Новая заявка с сайта теперь:
- сохраняется в Lead;
- появляется во внутреннем колокольчике Control;
- отправляет Web Push активным OWNER/MANAGER;
- сохраняет существующую email-отправку;
- по нажатию на push открывает /control/app.html#/leads.

Для iPhone/iPad: открыть Control в Safari, добавить на экран «Домой», открыть установленное веб-приложение и включить уведомления из раздела «Настройки».
