# Изображения цифровых продуктов — 18.10.2026

Выполнена замена трёх областей изображений в существующих панелях START / BUSINESS / SYSTEM. Вместо повторно нарисованных CSS-устройств используется готовая композиция ноутбука и смартфона с прозрачным фоном.

Файлы находятся в `site/image/products/`:

- `product-start.png`: «Тайна вкуса» + рабочее приложение «Свои грузы».
- `product-business.png`: «Ландшафт Парк» + административный интерфейс RioCar.
- `product-system.png`: «Сибирские Деликатесы» + «Этика волос», согласно присланному изображению SYSTEM.
- Для каждого PNG подготовлены прозрачные WebP и WebP шириной 768 px. Браузер выбирает WebP через picture/srcset; PNG остаётся запасным вариантом и отдельным исходником для дальнейшей работы.

Белый фон исходных PNG удалялся встроенным инструментом imagegen в режиме background-extraction. Файлы после такой обработки являются подготовленными презентационными визуалами, а не исходными скриншотами приложений. Прозрачность альфа-канала проверена. Сохранены переданные пары проектов.

Основная инструкция обработки: «Remove ONLY the connected exterior white background and make it truly transparent alpha. Preserve the supplied laptop and smartphone, including silhouettes, original perspective, screen content, Russian text, logos and colors. Do not redesign interfaces. Output transparent PNG.» Для START обработка повторялась с уточнением об удалении ореола.

Изменённые исходные файлы:

- `index.html`: только три figure с изображениями и версия CSS.
- `site/sass/main.scss`: только стили изображений справа, удалены неиспользуемые стили старых рамок устройств.
- `site/css/main.css`, `main.css.map`, `main.min.css`: пересобраны.

JavaScript, заголовки, цены, описания, переключатели, кнопки, фон и диагонали не изменены. BUSINESS активен по умолчанию. Старые графические файлы проекта сохранены, сервер, зависимости, Prisma и база не затронуты.

## Установка

Архив содержит полный проект. Перенесите обновлённые файлы в свою текущую папку ShumDev. Свои .env, базу и node_modules сохраните.

CSS уже собран; достаточно `npm run dev`. Новые зависимости и миграции не нужны. При дальнейших изменениях SCSS выполняйте `npm run build:public-css`.
